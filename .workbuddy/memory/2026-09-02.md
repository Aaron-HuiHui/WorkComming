### 修复清单（4 个真问题）
1. **未认证 403 空体 → 401 标准 Result**（SecurityConfig 补 exceptionHandling：authenticationEntryPoint→401+code10002 JSON、accessDeniedHandler→403+code10003）。前端 request.js 只认 401 跳登录，原行为导致 token 过期用户卡死。
2. **ResumeServiceImpl switch 模式匹配编译错**（Java 21 语法在 -source 17 下编译失败，且 case "translate" 与 Integer type 永不匹配的逻辑 bug）→ 改为 case 1/2（0润色/1翻译/2强化，对齐 ResumeAiGateway 约定）。这是增量构建一直掩盖的"编译炸弹"。
3. **登录限流误伤**：切面对无 X-User-Id 的匿名请求统一退化为 "anonymous"，所有未登录用户共享一个桶（rate=2/capacity=5，三次连续测试即 10004）→ 切面改为按客户端 IP（X-Forwarded-For→remoteAddr）隔离，登录限流放宽 rate=5/capacity=10。
4. **RabbitMQ DLX 声明冲突**：第十九阶段给队列加 x-dead-letter-exchange 参数，但 durable 旧队列不能改参数，每次重启 PRECONDITION_FAILED → 删除两个旧队列，服务重启后按新参数重建（已验证 4 队列 arguments 正确）。
