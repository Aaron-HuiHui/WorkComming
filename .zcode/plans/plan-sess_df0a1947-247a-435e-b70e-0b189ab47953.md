# 前端整体重构 · 第一期(设计骨架)

| 决策点 | 结论 |

## 设计语言(苹果官网 × 21st.dev)

- **深色模式(默认)**:苹果发布会深空黑底 `#050507`,文字 `#f5f5f7`,玻璃卡片 `rgba(255,255,255,.05)` + 1px hairline 边框,强调色为苹果系统蓝 `#2997ff`,辅以蓝→紫→品红渐变点缀
- **浅色模式**:苹果官网白 `#ffffff`/`#f5f5f7` 双底,按钮蓝 `#0071e3`,磨砂白卡 `rgba(255,255,255,.72)`
- **字体**:`-apple-system, SF Pro Display, Inter, system-ui` 字体栈(零下载成本,苹果设备原生 SF,Windows 走系统字体)
- **排版**:苹果式超大标题、大留白、克制的滚动渐入;hairline 细线代替粗边框

## 实施步骤

### 1. 前置检查与依赖安装
- 检查 node 版本(Tailwind v4 需 Node ≥ 20)、npm 镜像配置(必要时用 npmmirror,之前有下载超时前科)
- 安装:`tailwindcss @tailwindcss/vite @tsparticles/vue3 @tsparticles/slim`
- `vite.config.js` 加 `@tailwindcss/vite` 插件

### 2. 主题基建(核心)
- 新建 `src/styles/theme.css`:Tailwind v4 `@import "tailwindcss"` + `@custom-variant dark` + `:root`/`.dark` 双套语义 token(background/foreground/card/hairline/primary 等)
- **EP 主题对齐**:引入 `element-plus/theme-chalk/dark/css-vars.css`,并把 `--el-color-primary` 等 EP 变量指向我们的 token,EP 组件自动跟随深浅切换——这一步是 13 个未换皮页面在第二期前"不崩"的关键兜底
- 新建 `src/composables/useTheme.js`:初始化(系统偏好→localStorage)+ 切换 + watch 同步
- `main.js` 调整引入;删除 style.css 里 443 行硬覆盖中与新体系冲突的部分,保留对旧页面的兜底段(第二期再清)

### 3. 全局氛围层(App.vue)
- `ParticleBackground.vue`:tsParticles 封装,深色=银白微粒+鼠标半径连线,浅色=深灰低透明微粒,桌面 ~60 粒/移动端减量,fixed 全局层 pointer-events:none
- `AuroraBackground.vue`:CSS 渐变光斑漂移动画(替代现有 .aurora-bg),深浅两态
- 复用现有 `v-reveal` 滚动渐入指令

### 4. 刮刮乐组件 ScratchOverlay.vue(手写,全站记忆点)
- 整页 fixed canvas 遮罩:金属拉丝渐变涂层 + "开工大吉 · 刮开涂层"文案
- **硬币光标**:cursor:none,一枚带高光的 3D 感硬币 SVG 跟随鼠标(位移速度驱动轻微倾斜),划过处 `destination-out` 擦除
- 擦除时刮擦点飞溅金属微粒(独立轻量 canvas 粒子)
- 采样检测刮开面积,≥55% 触发遮罩淡出+粒子庆祝,进入仪表盘
- 右上角"跳过"按钮(照顾效率党);移动端 touch 支持降级为整页点击淡入

### 5. 新侧边栏+布局(MainLayout 重写)
- **Aceternity hover-expand 风格**:收起 64px 纯图标,鼠标悬停侧栏平滑展开 220px 菜单文字淡入,width/opacity CSS transition
- 新建 `src/config/menu.js` 单一配置源(菜单项+图标+角色+路由 meta 同源生成),消灭"路由/菜单/角色三处口径"的维护地雷
- 顶栏:页标题+通知铃铛(30s 轮询逻辑原样迁移)+积分+**ThemeToggle 深浅切换按钮**(太阳/月亮苹果风动画)+用户下拉
- 通知抽屉逻辑整体平移;保留 localStorage `userInfo` 契约(router 守卫依赖)

### 6. 首页 Dashboard 重写
- 挂 ScratchOverlay(每日首次进入触发,localStorage 记录日期)
- 苹果风 Hero:超大标题(用户名+今日激励语)+AI 状态 pill+双 CTA
- 统计带 4 卡(积分/徽章/演练/投递,HR 视角自动切换)、三大创新点导流卡(薪资白皮书/AI 模拟舱/防篡改徽章)
- 现有 GlassIcon 自绘 SVG 图标库评估保留

### 7. 登录页重写
- 苹果风居中玻璃卡+双 Tab(登录/注册)+演示账号提示保留,EP 表单组件不动只换皮

### 8. 验证
- `npm run dev` 启动,用浏览器 GUI 手测:登录→刮刮乐→仪表盘→侧栏展开→深浅切换→通知抽屉→各角色菜单(学生/HR/管理员三个账号)
- 全 15 页在新主题下过一遍,确认 EP 变量兜底无白底/黑字不可读
- 后端冒烟:登录/职位/通知接口走通(8080 网关)

## 明确不做(第二期)
13 个业务页(Jobs/HrJobs/Salary/JobMarket 等)的模板换皮、EP 深度定制、响应式精修、echarts 主题适配——等你在第一期风格上拍板后批量执行。

## 风险与对策
- **npm 下载超时**→ npmmirror 镜像 + allowScripts 已有先例
- **tsParticles 版本兼容**→ 用 v3 官方 vue3 封装,失败则降级为手写轻量粒子(已有 VelarisBackground 参考)
- **旧页面视觉回归**→ EP 变量对齐兜底 + style.css 救场段暂留
- **刮刮乐性能**→ 单 canvas + requestAnimationFrame,擦除半径采样降频,移动端降级
